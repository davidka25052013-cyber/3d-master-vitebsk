# 🥟🚀 Галактические Пельмени

Лендинг-магазин космических пельменей с неоновым дизайном, анимированным звёздным фоном и мини-корзиной. Реализовано по ТЗ: Mobile First, glassmorphism, параллакс, drawer-корзина с формой заказа.

## Структура

```
galactic-pelmeni/
├── index.html      # Hero, Меню (3 карточки), Footer, корзина-drawer
├── css/style.css   # Неоновые эффекты, glassmorphism, адаптив (mobile first)
└── js/main.js      # Корзина, счётчик, сумма, drawer, валидация, параллакс
```

## Запуск

Просто откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8080
# → http://localhost:8080/galactic-pelmeni/
```

## Реализовано по ТЗ

### 1. Верстка и дизайн
- ✅ Адаптивная сетка **Mobile First** (1 колонка → 2 при 640px → 3 при 980px)
- ✅ Анимированный фон: 3 слоя звёзд (радиальные градиенты, без картинок) + дрейфующие туманности + лёгкий параллакс при скролле
- ✅ Неоновое свечение текста (`text-shadow`) и кнопок (`box-shadow`)
- ✅ Анимация «невесомости» для пельменей (`@keyframes float-y` — покачивание + подъём)

### 2. Функционал
- ✅ Плавный скролл к меню (`scroll-behavior: smooth`, кнопки «Menu» / «Order Now»)
- ✅ Hover-эффекты: карточки (подъём + усиление свечения), кнопки (масштаб + заливка цветом)
- ✅ Мини-корзина: добавление, счётчик-бейдж, ± количества, подсчёт суммы, сохранение в `localStorage`
- ✅ Выезжающая панель (drawer) оформления заказа: Имя / Телефон / Адрес-шлюз, валидация, toast-уведомления, закрытие по Esc/фону

### 3. Оптимизация
- ✅ Изображения не используются вовсе — пельмени и фон нарисованы инлайн-SVG и CSS-градиентами (легче и резче любого WebP; при замене на фото — конвертируйте в WebP: `cwebp -q 80 in.jpg -o out.webp`)
- ✅ Кроссбраузерность: вендорные префиксы `-webkit-backdrop-filter`, фолбэки, поддержка `svh`, `env(safe-area-inset)`
- ✅ `prefers-reduced-motion` — анимации отключаются для чувствительных пользователей

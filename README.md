# 3D-Мастер Витебск — лендинг студии 3D-печати

Одностраничный посадочный сайт (лендинг) для генерации лидов на расчёт стоимости 3D-печати, выполненный по ТЗ заказчика.

## Структура проекта

```
├── index.html      — разметка всех 8 блоков лендинга
├── css/style.css   — тёмная технологичная тема, 100% адаптивность
├── js/main.js      — интерактив: квиз, слайдер, drag-and-drop, отправка заявок
└── README.md
```

## Блоки (по ТЗ)

| № | Блок | Реализация |
|---|------|-----------|
| 1 | Первый экран (Hero) | Заголовок + подзаголовок из ТЗ, визуальная схема «сломанная деталь → 3D-модель → готовое изделие», CTA-кнопка + иконки Telegram/Viber, цифры-статистика |
| 2 | Преимущества | 4 карточки (скорость, точность/материалы, моделирование под ключ, доступность) + полоса закрытия возражений |
| 3 | Что мы печатаем | 4 направления: автозапчасти, фигурки/мерч, прототипы, мелкосерия |
| 4 | Квиз-калькулятор | 3 шага: наличие файла → материал → drag-and-drop загрузка + контакт; валидация, маска телефона |
| 5 | Схема работы | 5 шагов «от идеи до готовой детали» со стрелками |
| 6 | Портфолио | Слайдер «До/После»: 4 кейса, свайп, стрелки, точки, автопрокрутка |
| 7 | FAQ | Аккордеон `<details>` с 4 вопросами из ТЗ |
| 8 | Контакты + подвал | Адрес, телефон, мессенджеры, форма обратного звонка, футер |

## Интеграция заявок в Telegram

В начале файла `js/main.js` находится блок настроек:

```js
var TG_CONFIG = {
  botToken: "",            // токен бота от @BotFather
  chatId: "",              // Ваш chat_id (узнать у @userinfobot)
  tgUsername: "vitebsk3d_test",
  fallbackEmail: ""        // резервный email
};
```

1. Создайте бота у **@BotFather** (`/newbot`) → скопируйте токен в `botToken`.
2. Узнайте свой `chat_id` → впишите в `chatId`.
3. Готово: все заявки (текст + прикреплённый STL/STEP/фото-файл) будут приходить в Telegram автоматически.

**Если токен не заполнен**, работает резервный сценарий: текст заявки копируется в буфер обмена и открывается чат `@vitebsk3d_test` — посетитель отправляет заявку вручную в один тап. Лид не теряется ни при каких условиях.

> ⚠️ Для продакшена прямое использование токена бота в JS раскрывает его посетителям. Правильный вариант — тонкий прокси-скрипт на сервере (PHP/Node), принимающий POST с формы и пересылающий в Telegram/email. Достаточно заменить URL в функции `sendToTelegram()`.

## Технические требования ТЗ

- **Адаптивность** — брейкпоинты 1080 / 760 / 420 px, бургер-меню, плавающая CTA-кнопка на мобильных (70%+ трафика B2C с телефонов).
- **Скорость загрузки** — никаких тяжёлых картинок: вся графика инлайн-SVG, шрифты с `preconnect`. При замене плейсхолдеров на реальные фото используйте WEBP ≤ 150 КБ с `loading="lazy"`.
- **Дизайн** — тёмная инженерная тема, неоновый зелёный акцент + оранжевый, сетка-«чертёж» на первом экране.
- **SEO/доступность** — meta description, Open Graph, Schema.org `LocalBusiness`, семантические теги, `aria`-атрибуты, поддержка `prefers-reduced-motion`.

## Как посмотреть

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Что заполнить перед запуском

- Реальный номер телефона вместо `XXX` (в `tel:`-ссылках и видимых текстах).
- Точный адрес точки выдачи в блоке «Контакты».
- Реальные фото кейсов вместо SVG-схем в слайдере портфолио (WEBP).
- `botToken` / `chatId` для приёма заявок.
